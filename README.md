# Self Introduction Website

This contains the page layout, with a header, a paragraph for course goals, and one for career goals. Under that, there is also a list for all my hobbies.

### style.css
This file contains the styling for my page. At the top is my color palette, which everything else references.

### scope.md
This details all the requirements for the project, and a more detailed description of its contents.
