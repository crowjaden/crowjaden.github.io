# Project Scope Statement

**Project Name:** Personal Introduction Webpage

## Project Purpose

The purpose of this project is to create a website that gives the instructor, classmates, or anyone I share it with a quick overview of who I am. It is also a starting point for learning to plan a project.

## Description

This project is a simple webpage containing information about myself. It will be hand-written in HTML, and will contain the following:
 - My name.
 - My major.
 - Professional interests.
 - Goals for this course and my career.
 - A list of my hobbies and interests.
 - A link to my GitHub.

It will be submitted by Nov 8, 2026, 11:59 PM.

## Desired Results

The website must be valid, checked with the W3C validator with 0 errors. The website must also include:
- A `<title>` inside `<head>`
- One `<h1>` with **my name**
- An `<h2>` with **my major or professional interests**
- At least **two** `<p>` paragraphs about **my goals for the course or my career**
- A `<ul>` with at least **three** `<li>` items listing **my hobbies or interests**
- An `<a href="https://github.com/crowjaden">` link to **my GitHub profile**
- Styled with a single external `style.css` (background color, fonts and colors for `<h1>` and `<p>`, spacing around the main content)

## Exclusions

This project will not include:
- Scripting.
- Images.
- Hosting or deployment.
